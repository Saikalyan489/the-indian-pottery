> *"Before words were carved on stone or forged in copper, our ancestors found life in river silt. In the wheel’s spinning rhythm and the kiln’s warm breath, they gave water a home and the earth a spirit."*

An interactive digital heritage pavilion and living educational archive exploring 10,000 years of unbroken Indian pottery traditions — from Neolithic Mehrgarh and Indus Harappan wheelcraft to rural Kumbhar communities and modern eco-conscious living.

Dedicated to the children, students, and next generation of India.

---

## ✨ Key Highlights

- **🏛️ 3D Digital Vessel Pavilion**:
  - Full 3D interactive viewer powered by Three.js.
  - Orbit, drag, rim inspection, and smooth pinch/zoom controls.
  - Authentic procedural clay shader textures reflecting alluvial river silt, Painted Grey Ware (PGW), and Northern Black Polished Ware (NBPW).
  - Integrated acoustic ring test demonstrating molecular vitrification (820 Hz resonant ceramic chime).

- **🎮 Potter’s Wheel Interactive Studio**:
  - Shape raw wet clay on a spinning wheel using dimensional sliders or historic presets (Mehrgarh Goblet, Indus Storage Jar, Mauryan Surahi, Village Matka, Temple Diya).
  - Fire the vessel in an earthen kiln above 700°C with mineral slip vitrification.
  - Tap the fired pot to listen to its pure ceramic chime.

- **🌐 6 Authentic Indian Languages**:
  - Full high-quality native translations in **English**, **Telugu (తెలుగు)**, **Hindi (हिन्दी)**, **Tamil (தமிழ்)**, **Malayalam (മലയാളം)**, and **Kannada (ಕನ್ನಡ)**.
  - Non-intrusive floating guide on entry and language switcher.

- **📱 Fluid & Ultra-Responsive**:
  - Optimized for both mobile smartphones and widescreen desktop monitors.
  - Touch-friendly 3D orbit, gesture controls, and clean compact layouts.
  - Smooth micro-animations with Framer Motion.

- **⚡ Blazing Fast Performance & SEO**:
  - Instant loading via Google Cloud Global CDN Edge network on Firebase Hosting.
  - Schema.org `EducationalWebSite` JSON-LD structured data for rich Google Search results.
  - `robots.txt` and `sitemap.xml` configured for search crawler discovery.

## 📖 Chapters Covered

1. **Before Clay Pots** — Stone-age hollow stones, woven grass lined with mud, and the dawn of fired vessels.
2. **How Pottery Began in India** — Neolithic Mehrgarh (7000 BCE) handmade cord-impressed pottery to early turntable inventions.
3. **Pots of Ancient India** — Indus Valley terracotta, Painted Grey Ware (PGW), Northern Black Polished Ware (NBPW), and royal trade amphorae.
4. **Pots We Use Every Day** — The cooling physics of the Matka, festive Diwali Diyas, fragrant railway Kulhads, and fragrant Biryani Handis.
5. **How a Clay Pot Is Made** — Silt harvesting, foot-kneading, wheel throwing, paddle-beating (*thapa-pindi*), and wood-straw kiln firing.
6. **Clay in Daily Life** — Natural bio-cooling, curd fermentation, porous toxin-free cooking, and 100% biodegradable return to earth.
7. **The People Who Make the Pots** — Kumbhar, Prajapati, and Kumhar generational guilds preserving living wisdom.
8. **Indian Pottery Today** — Studio ceramics, modern eco-revival, terracotta water bottles, and artistic heritage.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Saikalyan489/The-Indian-Pottery.git

# Navigate to project folder
cd "The Indian Pottery"

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

The optimized static production bundle will be generated in `dist/`.
