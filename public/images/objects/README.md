# Traditional Pottery Objects Photographs

Place photographs of traditional Indian pottery vessels here:
- `matka` / `ghada` (water cooling pots)
- `surahi` (narrow-neck cooling flasks)
- `handi` / `degchi` (cooking pots)
- `diya` (earthen oil lamps)
- `kulhad` (earthen tea cups)
- `tawa` (earthen flat pans)
